# Project guidance

## Context

Context Engine independently reproduces A-Mem and AgeMem through a CLI before exploring a hybrid approach. Current implementation work focuses on A-Mem.

- Read `README.md` for the roadmap.
- Research papers are in `docs/reference_research/`.
- The infrastructure checklist is `docs/implenentation/phase_0.md`.
- Planned stack: Python, SQLAlchemy, Pydantic Settings, and PostgreSQL with pgvector in Docker.

## Working conventions

- Read `AGENTS.local.md` when present and apply its local collaboration preferences.
- Keep documentation clear about what is planned and what is implemented.
- Keep phase checklists focused on steps and references, without implementation recipes unless requested.
- Preserve source evidence when discussing memory evolution and distinguish paper requirements from project design choices.
- Keep changes within the requested scope and never commit credentials.
